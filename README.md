## שפה עיצובית
נגזרת מהלוגו: נייבי `#16294A`, זהב `#B08D57`, טורקיז `#2E6F82`, קרם `#FBF8F3`.
כותרות ב-Rubik, גוף ב-Assistant. שפת כרטיסים מרחפים: פינות מעוגלות (20-28px), צללים רכים ורחבים,
מיכל 1180px, ריתמוס רקעים מתחלף בין סקשנים.
סקשן העץ בנוי ככרטיס מרחף עם ניווט נקודות, בהשראת רפרנס שסופק על ידי הלקוח.

## הפרדת תוכן: מאמרים מול הדרכה
נושאי ההדרכה (lead magnet) — מכשירים, מיסוי, פיזור, למה פיקדון מפסיד — לא מוצו באתר.
המאמרים באתר מכסים זוויות משלימות (עלויות, מסלולים פנסיוניים, סדר פעולות אחרי ירושה)
כדי שלא תהיה חפיפה בין השניים.
