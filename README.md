# שילינגר תכנון פיננסי — אתר תדמית

אתר סטטי (HTML/CSS/JS, ללא תלויות build) בעברית RTL, על בסיס בריף האסטרטגיה השיווקית.

## מבנה
| קובץ | תיאור |
|---|---|
| `index.html` | עמוד הבית — מסך פתיחה, הבעיה, האויב המשותף, מי אני, השירותים, למה לבחור בי, איך זה עובד, המלצות, לוגואים, טופס |
| `services.html` | ריכוז השירותים + התהליך |
| `service-new-money.html` | שירות 1 — ניהול כסף חדש (ירושה / אקזיט / מכירת עסק) |
| `service-portfolio.html` | שירות 2 — אסטרטגיית השקעה להון פנוי |
| `service-pension.html` | שירות 3 — אופטימיזציה של כספים פנסיוניים |
| `about.html` | אודות |
| `articles.html` | מאמרים מקצועיים |
| `contact.html` | צור קשר + שאלות נפוצות |
| `assets/css/style.css` | מערכת העיצוב |
| `assets/js/main.js` | תפריט מובייל, אנימציות כניסה, טיפול בטופס |

## שפה עיצובית
נגזרת מהלוגו: נייבי `#1B2F52`, זהב `#B08D57`, טורקיז `#2E6F82`, קרם `#FAF6F0`.
כותרות ב-Frank Ruhl Libre, גוף ב-Heebo. שני סוגי כרטיסים בלבד (בהיר / כהה), רדיוס 12px,
מיכל 1140px, ריתמוס רקעים מתחלף בין סקשנים.

## הפרדת תוכן: מאמרים מול הדרכה

כדי שלא תהיה חפיפה בין השניים.
